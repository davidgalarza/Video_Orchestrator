# Código de conducta

Queremos que contribuir a Vidgen Studio sea una experiencia respetuosa y accesible.

- Critica decisiones y código con ejemplos concretos, sin atacar a las personas.
- Respeta distintas experiencias, capacidades, identidades y niveles de conocimiento.
- No publiques información privada, credenciales ni contenido ajeno sin permiso.
- No se aceptan acoso, amenazas, discriminación, spam ni conductas que dificulten deliberadamente la participación.

Estas pautas se aplican a incidencias, PR y otros espacios oficiales del repositorio. Los mantenedores pueden editar o retirar contenido, cerrar conversaciones o limitar la participación para proteger el espacio de colaboración, atendiendo al contexto y gravedad.

Para pedir intervención, contacta a un mantenedor mediante los canales que tenga publicados en GitHub. Si no hay canal privado, solicita uno sin exponer detalles personales en público. No se promete confidencialidad para contenido publicado en una incidencia pública.

Este es un código breve propio del proyecto; no declara adhesión a una política externa ni garantiza plazos de respuesta.
